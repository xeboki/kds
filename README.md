# Xeboki KDS

Xeboki Kitchen Display System: real-time order management for professional kitchens, connected to [Xeboki POS](https://xeboki.com).

Built with Flutter and Dart.

## Getting started

```bash
git clone https://github.com/xeboki/kds.git
cd kds
flutter pub get
flutter run
```

You need a Xeboki account and API access. See the [Xeboki developer portal](https://developers.xeboki.com).
